Tempest Discord Companion — PebbleHost bundle

1. Preserve any existing bot files before extracting this bundle.
2. Copy .env.example to .env and enter secrets only in PebbleHost.
3. Install the dependencies from package.json.
4. Use Node.js 22.19 or newer and start with: npm start

The bot token belongs only in PebbleHost. TEMPEST_SIGNAL_DISCORD_WORKER_TOKEN
must exactly match Tempest Signal's worker token. Never commit either value.
