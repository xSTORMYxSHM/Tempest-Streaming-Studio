USING SAFE DEFAULTS
BROADCASTER SETUP

Connect it once in Studio

  1. Open Tempest Streaming Studio, then go to Twitch → Companion Extensions.
  2. Pair the channel with Tempest Signal and enable the Tempest Streaming · Video Overlay companion.
  3. Choose which features appear in Streaming and save. Studio publishes the action list, access rules, cooldowns, and placement settings automatically.
  4. Keep Studio online and keep its Unified Stage Browser Source active in the broadcast scene so accepted effects appear in the encoded stream.
REVIEWER + VIEWER TEST

Verify an action in under two minutes

  1. Open the live channel and reveal the Extension over the Twitch video.
  2. Select ACTIONS. The header should change from CONNECTING to STUDIO ONLINE.
  3. Select any available action. If a targeting grid appears, click or tap the desired point on the video.
  4. Confirm the accepted message in the Extension and the resulting effect in the stream video. A locked or cooling-down action explains why it is unavailable.

Expected offline state: If Studio is not connected, the Extension shows STUDIO OFFLINE and asks the creator to open Studio. No additional viewer account or credentials are required; Twitch authorization supplies viewer identity.
