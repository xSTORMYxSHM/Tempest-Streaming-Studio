PLAYGROUND NODE
  1. 1
    Open your interaction blueprint

    In Warudo, open the blueprint that already contains your dance or reaction branches.

  2. 2
    Add “Tempest Performance Cue”

    Copy the supplied C# file to Warudo's Playground folder, then add Tempest Performance Cue from the node palette.

  3. 3
    Connect and test both flows

    Use an exact cue, comma-separated cues, or a trailing wildcard such as sound-alert.*. Connect Activate to the performance and Release to the restore animation, then press Test Activate and Test Release on the node.
